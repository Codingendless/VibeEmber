# VibeEmber · 起飞场

### 为 Vibe Coder 而生的产品首发与冷启动互助社区

**好产品，不该从 0 个用户开始。**

VibeEmber 是一个面向 Vibe Coder、独立开发者和小型创业团队的产品社区。你可以在这里发布刚刚做出来的产品，获得第一批真实体验者、使用反馈和初始曝光。

社区不会替你解决产品与运营的所有问题，但它可以让一个真正做出来的产品，不再死在“没人知道”这一关。

> 先一起跨过冷启动，然后各凭本事起飞。

## 进入社区

👉 **[https://wenxinxu.com/VibeEmber/](https://wenxinxu.com/VibeEmber/)**

项目目前处于早期内测阶段。欢迎发布真实作品、参与体验，也欢迎一起建设社区规则。

## 我们想解决什么

Vibe Coding 降低了产品开发的门槛，但没有降低产品发布和获得用户的门槛。

很多开发者会遇到这些情况：

- 产品已经上线，但没有人知道
- 缺少首批用户，无法判断真实需求
- 自己用着没问题，别人一用就卡住
- 需要少量真实用户完成早期测试
- 花了很多 Token 做产品，却没有验证它能不能赚钱
- 不知道别人是否已经做过类似产品
- 没有团队，也没有稳定的开发者圈子

VibeEmber 将分散的独立开发者聚集在一起，让每个人既可以展示作品，也可以成为别人的第一批用户。

## 谁适合加入

- 用 AI 和 Vibe Coding 制作产品的开发者
- 正在运营小程序、Web 应用、App 或浏览器插件的个人
- 需要真实体验反馈的早期产品团队
- 想找项目灵感、合作伙伴或细分赛道的人
- 愿意先认真体验别人产品，再获得社区帮助的人

不会写代码也可以加入。只要你愿意认真体验产品、提供有效反馈，就是社区有价值的成员。

## 社区怎么玩

```text
注册开发者账号
        ↓
发布你的真实产品
        ↓
通过社区审核并公开展示
        ↓
发起真实体验或冷启动任务
        ↓
获得首批用户与反馈
        ↓
根据反馈改进产品，开始真正运营
```

### 1. 注册账号

使用邮箱创建开发者账号。后续发布的产品、审核状态和互助记录都将与该账号关联。

### 2. 发布产品

填写产品名称、一句话介绍、访问链接、产品类型，以及目前最需要的帮助。

好的投稿不需要写成商业计划书，只需要讲清三件事：

1. 这是什么产品？
2. 它为谁解决什么问题？
3. 你现在需要什么样的真实帮助？

### 3. 等待审核

新项目默认进入审核队列。管理员会确认项目是否可以正常访问、介绍是否真实，以及是否符合社区公约。

- **审核中**：项目已提交，但还未公开
- **已上线**：项目已通过审核，出现在社区首页
- **已驳回**：项目需要修改，投稿者可查看驳回原因

### 4. 帮助别人

浏览社区中的产品和互助任务，选择你真的能完成的任务。完成体验后，给出有信息量的反馈，而不是只说“很好用”。

有价值的反馈可以是：

- 哪一步不知道怎么继续
- 你原本以为某个按钮会发生什么
- 什么功能真的解决了你的问题
- 什么情况下你愿意再次使用或付费
- 你更愿意将它推荐给哪类人

### 5. 发起互助

通过帮助其他产品获得社区火苗，再用火苗为自己的产品发起冷启动任务。

例如：

- 征集 20 位目标用户完成 10 分钟真实体验
- 寻找特定城市、行业或语言的用户试用
- 征集 iOS、Android 或特定设备的兼容性反馈
- 请用户完成某个关键流程并记录卡点
- 寻找首批愿意持续使用的种子用户

## 火苗是什么

火苗是社区中用来记录贡献的互助积分。

```text
认真体验产品 + 提交有效反馈 → 获得火苗
发起自己的冷启动任务           → 消耗火苗
```

火苗不用来购买虚假用户，而是用来让“先帮别人”的人优先获得帮助。

相关的积分明细、任务验收和防作弊机制正在建设中。

## 社区怎么运营

VibeEmber 不是单纯的应用导航站，也不是付费刷量平台。社区的运营围绕“真实产品、真实用户、真实反馈”展开。

### 产品审核

每个新项目都要先通过审核，尽量阻止无法访问的链接、诱导下载、恶意软件、违法内容和纯拉新项目进入社区。

### 真实体验

互助任务应该要求参与者真正打开、使用和理解产品。只有点击、注册但没有真实体验的行为，不应被认定为有效贡献。

### 贡献优先

更愿意帮助别人、反馈质量更高、任务完成记录更好的成员，会获得更高的信用和曝光权重。

### 公开与透明

项目的审核状态、互助需求和任务进度应尽量清晰展示。管理员驳回项目时需要留下原因，而不是让投稿者猜。

### 反作弊

对虚假账号、批量机器点击、复制粘贴反馈、诱导好评和绕过平台规则的任务，社区将降低权重、取消贡献或停用账号。

## 社区能帮你什么

- 让真实产品获得第一批用户
- 快速发现产品理解、使用流程和兼容性问题
- 获得来自其他开发者的具体反馈
- 在正式投放广告前完成小规模验证
- 看到社区中已经出现的产品和赛道
- 寻找种子用户、合作者和联合推广机会
- 让长期只做产品的开发者开始学会发布和运营

## 社区不会替你做什么

- 不保证任何产品获得收入
- 不用虚假用户制造繁荣数据
- 不代替产品本身的价值与长期运营
- 不承诺帮助项目绕过第三方平台审核
- 不鼓励违反微信、应用商店、广告或社交平台规则的行为
- 不会因为一次互助就自动带来长期增长

社区解决的是从 0 到 1 的启动问题。跨过这一步以后，产品能不能留住用户、形成传播和获得收入，仍然要靠产品与运营。

## 社区公约

### 我们鼓励

- 发布自己真正参与制作的产品
- 清楚说明产品现阶段的问题和需求
- 给出可执行、有上下文的体验反馈
- 尊重每一个还很粗糙的早期产品
- 对产品、数据、合作关系和收益保持诚实
- 将好的产品推荐给真正需要的人

### 我们拒绝

- 恶意软件、诈骗、钃鱼和违法内容
- 没有真实体验的批量点击与注册
- 刷广告、刷好评、刷排名和其他虚假数据
- 诱导或强迫参与者提供好评
- 抄袭他人产品、素材、介绍或投稿内容
- 泄露体验过程中接触到的隐私和测试数据

## 运营发展路线

### 阶段一：创始社区

- 邀请第一批真实开发者发布项目
- 人工审核每个新产品
- 人工组织体验与反馈小组
- 根据真实使用情况调整社区规则

### 阶段二：完成互助闭环

- 上线真实互助任务和任务验收
- 上线火苗积分明细
- 建立开发者信用与贡献记录
- 添加评论、收藏、通知和项目里程碑

### 阶段三：形成可持续运营

- 优质项目首发日与主题活动
- 城市、行业和平台垂直互助小组
- 优质产品专访、案例拆解与运营复盘
- 付费置顶、首发活动和团队服务等商业化尝试
- 与开发者工具、云服务和流量平台建立合作
